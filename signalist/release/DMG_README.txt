SIGNALIST — ПЕРШИЙ ЗАПУСК

Дякуємо, що встановлюєте Signalist. Перш ніж почати, виконайте два кроки.

1) ВСТАНОВЛЕННЯ

Перетягніть Signalist.app у папку Applications (значок поруч у цьому вікні).

2) ПЕРШИЙ ЗАПУСК: «Програму пошкоджено, її не можна відкрити»

Збірки Signalist поки не нотаризовані Apple, тому macOS Gatekeeper при першому
запуску покаже помилку про «пошкодження» програми. Це не справжнє пошкодження —
це quarantine-атрибут, який браузер додає до будь-якого завантаженого файлу.

Відкрийте Terminal (Програми → Утиліти → Термінал) і виконайте одну команду:

    xattr -cr /Applications/Signalist.app

Після цього запустіть Signalist ще раз — він відкриється нормально.

Команду потрібно повторювати лише після ручного завантаження нового .dmg.
Автоматичні оновлення всередині застосунку цього не потребують.

ВИМОГИ ДО СИСТЕМИ

- macOS 14 Sonoma або новіше
- Mac з процесором Apple Silicon (M1/M2/M3/M4 тощо)

Збірки для Intel Mac наразі не публікуються. Якщо ваша версія macOS старіша —
Signalist повідомить про це при запуску і підкаже, що робити.
